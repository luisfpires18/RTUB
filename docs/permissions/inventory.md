Source: `InventoryAuthorization`. Page doc: [react-inventory](../react-inventory.md).

| --- | --- |
| Visitor | `401` |
| Any signed-in member | list, counters, every instrument's details |

| Mod, Admin, Owner | create, edit, set the image, delete instruments |
