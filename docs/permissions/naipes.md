# Permissions: /naipes and /naipes/config

Source: `NaipesAuthorization`. Page doc: [react-naipes](../react-naipes.md).

| Who | What |
| --- | --- |
| Visitor | `401` |
| Any signed-in member (Leitão included) | read; add videos and images; comment; edit and delete what they added; delete their own comments |
| Admin, Owner | edit and delete anyone's videos, images, comments; change instrument settings |
| Mod | no extra rights |
