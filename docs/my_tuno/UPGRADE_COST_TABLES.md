# My Tuno — Upgrade Cost Tables

**Fidelis Formula (Quadratic):** `Cost(n) = baseCost + n² × costScale` where `n` = current upgrade count (0-indexed)

**Fidelis Formula (Linear, Speed/Crit only):** `Cost(n) = baseCost + n × costPerLevel`

**Leitão (Piggies) Formula:** `Cost(n) = baseCost + (n - startLevel) / costEveryNLevels` (integer division). Returns **0** below `startLevel`.

## Summary

| Stat | baseCost | costScale | Max Lvl | Flat Bonus/Lvl | Leitão Start Level |
|------|----------|-----------|---------|----------------|---------------------|
| HP | 80 | 1,000 | ∞ | +8,000 HP | **10** |
| Power | 80 | 1,000 | ∞ | +1,200 Power | **10** |
| Defense | 80 | 1,000 | ∞ | +960 Defense | **10** |
| **Speed** | **175** | **175/lvl** | **41** | +1.5 Speed | **20** |
| **Crit** | **140** | **140/lvl** | **100** | +0.5% Crit | **50** |

> HP/Power/Defense use **quadratic** costs (`baseCost + n² × costScale`). Speed and Crit remain **linear** (`baseCost + n × costPerLevel`).

### Leitão Costs for Stat Upgrades

Leitão cost begins at **level 10** for stat upgrades (HP, Power, Defense). Speed (max 41) and Crit (max 100) use different start levels.

| Config Key | Value |
|------------|------:|
| `statUpgradeStartLevel` | 10 |
| `statUpgradeBaseCost` | 1 |
| `statUpgradeCostEveryNLevels` | 5 |

| Level Range | Leitão Cost |
|-------------|------------:|
| 1–9 | 0 |
| 10–14 | 1 |
| 15–19 | 2 |
| 20–24 | 3 |
| 25–29 | 4 |
| 30–34 | 5 |
| ... | +1 every 5 levels |

Leitões are earned exclusively from **Boss Mode** victories.
