# My-Tuno layers (single source)

This is the **only** character layer folder used by the customizer.

Assets are text-based SVG so diffs are reviewable:

- `body/base.svg`
- `eyes/base.svg`
- `hair/*.svg` (3)
- `clothes/*.svg` (3)
- `weapons/*.svg` (11)

Regenerate all layers:

```bash
python scripts/generate_my_tuno_layers_svg.py
```
